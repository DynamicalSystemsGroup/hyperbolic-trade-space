## Q8. Judged three ways

- Against the Home page: it is the Home page, word for word; nothing missing, nothing added.
- Against the root page: consistent. It carries the root page's "beside PCA ... the two chain" framing and the scikit-learn method list, and its "Where to start" list matches the root page's description of the docs (first fit, per-task guide, API reference, cubesat example, model in brief, glossary), adding "Further reading". The root page's word "n-lemma" and "tension report" do not appear here; the Home page says "monomial term" and "which metrics contend" instead, so a reader moving from the root page to the docs meets two names for what seem to be the same things.
- Against its own opening sentence ("learns the shape of a design trade space from evaluated designs"): the rest of the page does what it says. The first paragraph explains the input and the outputs, and the list tells the reader where to go to do it.

Paragraphs that serve none of the three:

- "The workflow serves design optimization and configuration management: ..." The root page does not mention configuration management, and nothing else on the page picks up "tracking a configuration's evaluation"; it reads as a claim of scope with no follow-through here.

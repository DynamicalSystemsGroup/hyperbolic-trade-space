The three strongest

1. Perovskite Database Project. A documentation example on it would show configurations that really are design choices: layer stack, composition and process route. The synthetic satellite has none of that. Its rows are independent literature reports, so the example would also show what the method does with missing cells and repeated devices. That is a stress the synthetic model does not apply. The attributes are PCE, Voc, Jsc and FF; check which stability metric is populated. All four are positive and larger-is-better, so no orientation change is needed. PCE is the product of the other three divided by input power, so the example must say the attribute set is not independent: one attribute is redundant, and the fit will reveal that. Scale: Voc in volts, Jsc in mA per cm squared, FF as a fraction and PCE in percent. Drop zeros and out-of-range values (FF above 1, which the curation pipeline may admit). A stability measure such as T80 hours is larger-is-better and spans orders of magnitude, so shift is not needed but a log-scale choice would be. Verify the column names first.

2. Amniote life-history database. It would show a natural-science analysis with no engineered design variables. Class and order are the categorical configuration, and body mass is the covariate whose effect a user may need to partial out. It lets the example state the method's boundary honestly: observational data, no designer in the loop. Conditioning per attribute: longevity (years) is larger-is-better and needs no inversion; litters per year and litter size are larger-is-better for fecundity; maturity age (days) and gestation (days) are time-costs, so invert (1/x) if fast is the goal, or use as-is if slow is the goal. State that choice, because it sets which attributes trade. Mass (g) spans eight orders of magnitude, so rescale by the median or the geometric mean. Zero and negative sentinels (the database codes missing as -999) must be removed; I did not verify this from the file.

3. Gorsse high-entropy alloy compilation. It is the closest match to a classic engineering trade-off on measured data. The configuration is a composition vector, which fits the package's arbitrary-dimension arrays and has a natural simplex constraint. The example would show an inversion-free trade (yield strength against elongation) and mixed units. It is the weakest on source: the data sit in a supplement, and the Data in Brief correction of 2020 (vol. 32, 106216) must be applied. Conditioning: yield and ultimate strength (MPa) and hardness (HV) are larger-is-better, scale by their median; elongation (%) is larger-is-better and can be zero for brittle failure, so apply a small shift or drop zeros; Young's modulus and density are partly estimated by rule of mixtures, so exclude them from the attribute set and list them as non-measured. Compression and tension are different tests, so keep test type as a categorical configuration, not a pooled attribute. Check the complete-case count before committing.

If the supervisor wants a natural-science fallback with the cleanest licence, the Dryad Global Amax dataset (doi:10.5061/dryad.j42m7) is the nearest match, pending its licence field. GLOPNET and PanTHERIA are good scientifically but lack a verified open licence.

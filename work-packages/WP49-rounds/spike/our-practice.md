## What the record does not contain

- **No `CONTRIBUTING.md` or `CODE_OF_CONDUCT.md`.** `README.md` line 41 names `CLAUDE.md` as "conventions for contributors
  working with Claude Code"; no file addresses a contributor who is not working under the supervisor's process.
- **No pull-request template in `.github/`** (only `workflows/test.yml` and `workflows/pages.yml` are there); so the
  pull request's description is not today a recorded place for tool documentation.
- **The attribution check is a grep for trailers, not a check of who is accountable.** It finds an AI line in a message; it
  does not check that a named person owns the change, and the history cannot show an outside contributor because there
  has been none (one author across the history).
- **The "human stands behind a change" statement is a process, not a stated commitment to a user.** P5 and P7 are rules to
  agents and contributors; no file tells a user that a named person owned each merge. The supervisor's words of
  2026-11-14 state the principle; no repository document yet states it as a promise.
- **The tool stance of 21:10 is in `WP49-decisions.md` only**, not in `CLAUDE.md` or the README.

# Case: an ADCS trade study

The case is told in the paper, which walks a spacecraft attitude determination and control (ADCS)
trade study through the method, from the evaluated configurations to the tensions and the gaps. The
[paper](../../paper/) is the place to read it.

The code and data behind the case are in the repository under
[`examples/adcs/`](https://github.com/DynamicalSystemsGroup/hyperbolic-trade-space/tree/main/examples/adcs/):
the design space and the evaluation model, the committed seeded datasets, the figures, and the
script that reproduces the fits. The method pages explain what each step does:
[Why and how](why-and-how.md) for the idea, [Preconditioning](preconditioning.md) for the step from
attributes to metrics, and [Mathematics](method.md) for the results the case relies on.
